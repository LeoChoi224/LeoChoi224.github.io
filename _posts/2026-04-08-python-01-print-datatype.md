## 파이썬은 위에서 아래로 읽는다
`.py` 파일은 그냥 글자가 적힌 텍스트 파일이다.

파이썬 인터프리터가 이 파일을 **위에서 아래로 한 줄씩 읽으면서** 시키는 대로 실행한다. 그래서 코드의 순서가 곧 실행 순서가 된다.

나중에 배우게 될 조건문, 반복문, 함수는 전부 이 "위에서 아래로" 흐름을 일부러 바꾸는 장치라고 한다.

## 첫 프로그램 print()
`print()`는 괄호 안의 내용을 화면에 출력하고 줄을 바꾸는 함수다.

```python
print("안녕하세요")
print("좋은 아침" + " 여러분")
```

프로그램이 안에서 무엇을 하고 있는지는 사람이 직접 볼 수 없다. 그래서 가장 먼저 배우는 것이 안을 들여다보는 창 역할을 하는 `print()`라고 한다.

코드가 생각대로 안 돌아갈 때 제일 많이 쓰게 될 도구도 결국 `print()`일 것 같다.

## + 는 타입에 따라 다르게 동작한다
오늘 가장 기억에 남는 부분이다.

```python
print(55 + 31)      # 86
print("55" + "31")  # 5531
```

같은 `+` 기호인데 숫자끼리는 **덧셈**이 되고, 문자열끼리는 **이어붙이기**가 된다.

파이썬은 `+` 양쪽 값의 **타입**을 먼저 보고 어떤 동작을 할지 정한다. `55`와 `"55"`는 화면에 비슷하게 보여도 완전히 다른 값이다. 따옴표가 있으면 숫자가 아니라 글자다.

```python
print("55" + 31)  # TypeError
```

그래서 글자와 숫자를 `+`로 붙이면 에러가 난다. 파이썬 입장에서는 덧셈을 하라는 건지 이어붙이라는 건지 알 수 없기 때문이다.

## 숫자형 int와 float
숫자는 소수점이 없는 정수 `int`와 소수점이 있는 실수 `float`로 나뉜다.

```python
print(10)     # int
print(10.0)   # float
print(10.)    # 10.0  소수점만 찍어도 실수
print(.1)     # 0.1   앞의 0은 생략 가능
```

연산 결과의 타입에도 규칙이 있었다.

```python
print(4 * 5)    # 20    int × int → int
print(4 * 5.0)  # 20.0  하나라도 실수면 실수
print(4 / 2)    # 2.0   / 는 딱 떨어져도 무조건 float
print(4 // 2)   # 2     // 는 몫
print(13 % 3)   # 1     % 는 나머지
print(2 ** 4)   # 16    ** 는 제곱
```

`/`는 나누어 떨어져도 항상 `float`를 만든다는 점이 의외였다. 정수 결과가 필요하면 `//`를 쓰거나 `int()`로 바꿔야 한다.

## 실수는 정확하지 않다
```python
print(2.1 + 0.2)          # 2.3000000000000003
print(2.1 + 0.2 == 2.3)   # False
```

컴퓨터는 숫자를 2진수로 저장하는데, 0.1 같은 10진 소수는 2진수로 바꾸면 끝없이 반복되는 수가 된다. 어딘가에서 잘라서 저장해야 하니 아주 작은 오차가 남는다.

그래서 **실수끼리는 `==`로 비교하면 안 된다.** 이건 파이썬만의 문제가 아니라 거의 모든 프로그래밍 언어가 똑같다고 한다.

실무에서는 `abs(a - b) < 0.000001`처럼 차이가 충분히 작으면 같다고 보거나, 돈 계산처럼 오차가 있으면 안 되는 곳에서는 `decimal` 모듈을 쓴다고 한다.

## 문자열 str
문자열은 따옴표 네 가지로 만들 수 있다.

```python
print('Python is fun')
print("Python is fun")
print("""Python is fun""")
print('''Python is fun''')
```

이렇게 여러 가지가 있는 이유는 **문자열 안에 따옴표가 들어갈 때** 필요하기 때문이다.

```python
print("She's gone")    # 안에 홑따옴표가 있으니 바깥은 쌍따옴표
# print('She's gone')  # 에러! 어디서 끝나는지 알 수 없다
```

따옴표 세 개는 여러 줄을 그대로 쓸 때 사용한다.

```python
print("""동해물과 백두산이
마르고 닳도록""")
```

문자열에도 쓸 수 있는 연산이 있다.

```python
print('😀' * 20)             # 반복
print(len('hello python'))  # 12  공백도 한 글자로 센다
print('hello' '로켓')        # 붙여 쓰면 자동으로 이어진다
```

## bool과 None
비교 연산자와 논리 연산자의 결과는 항상 `True` 아니면 `False`인 `bool` 타입이다.

```python
print(20 > 10)       # True
print(10 >= 10)      # True
print(10 * 2 != 10)  # True
```

`None`은 "값이 없음"을 나타내는 전용 값이다.

```python
print(None)
```

0도 아니고 빈 문자열도 아니고, 아직 아무것도 정해지지 않았다는 뜻이다. 함수가 아무것도 돌려주지 않을 때 이 값이 나온다고 한다.

## type()으로 타입 확인하기
값의 타입이 헷갈릴 때는 `type()`으로 직접 확인할 수 있다.

```python
print(type(10))      # <class 'int'>
print(type(10.0))    # <class 'float'>
print(type("10.0"))  # <class 'str'>  따옴표가 있으면 글자
print(type(True))    # <class 'bool'>
print(type(None))    # <class 'NoneType'>
```

파이썬은 자바나 C처럼 `int a = 10;` 같은 식으로 타입을 미리 적지 않는다(동적 타입). 편한 대신, 지금 이 변수에 무엇이 들어 있는지 사람이 계속 기억하고 있어야 한다.

수업 중에 강사님이 "타입! 값!"을 계속 강조하신 이유를 조금은 알 것 같다.

## 들여쓰기도 문법이다
파이썬은 줄 앞의 공백에 의미가 있다.

```python
print(100)
#  print(200)   ← 이유 없이 들여 쓰면 IndentationError
print(300)
```

다른 언어가 `{ }`로 코드를 묶는 것을 파이썬은 들여쓰기로 묶는다. 조건문을 배우면서 본격적으로 쓰게 된다고 한다.

## 헷갈리기 쉬운 부분
- `print(100)`과 `print("100")`은 화면에 똑같이 보이지만, 앞의 것은 숫자이고 뒤의 것은 글자다. 출력 결과만 보고 타입을 판단하면 안 된다.
- `-3 ** 3`은 `-27`이다. `**`가 `-`보다 먼저 계산된다.
- `print(5 / 0)`은 `ZeroDivisionError`가 난다.
- 한 줄에 `;`로 여러 문장을 쓸 수는 있지만(`print(100); print(200)`), 파이썬에서는 쓰지 않는 것이 관례다.

## 오늘 배운 내용 정리
오늘은 첫 프로그램과 파이썬의 기본 자료형을 배웠다.

```
print(): 괄호 안의 값을 화면에 출력한다.
+ 연산자: 숫자끼리는 덧셈, 문자열끼리는 이어붙이기. 타입이 동작을 정한다.
int / float: 정수와 실수. / 는 항상 float, // 는 몫, % 는 나머지, ** 는 제곱.
실수 오차: 실수끼리는 == 로 비교하지 않는다.
str: 따옴표 4종류로 만들고, * 로 반복, len() 으로 길이를 잰다.
bool / None: 참·거짓 값과 "값이 없음"을 나타내는 값.
type(): 값의 타입을 확인한다.
들여쓰기: 파이썬에서는 문법이다.
```

첫날이라 코드 양은 적었지만, **값에는 타입이 있고 타입이 연산 결과를 바꾼다**는 점은 확실히 기억해둬야 할 것 같다.

앞으로 값이 이상하게 나오면 일단 `type()`부터 찍어보는 습관을 들이려고 한다.
