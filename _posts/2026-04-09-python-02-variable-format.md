어제는 `print()`와 기본 자료형을 배웠고, 오늘은 값에 이름을 붙이는 **변수**와 타입을 바꾸는 **형변환**, 그리고 값을 문장 안에 끼워 넣는 **출력 포맷팅**을 배웠다.

수업 중간에는 프로젝트마다 파이썬 패키지를 따로 담아두는 가상환경(virtual environment)도 설치했고, 정올(jungol) 사이트의 "출력" 단원 문제도 풀기 시작했다.

오늘 배운 내용을 기준으로 변수와 포맷팅의 흐름을 정리해보려고 한다.

## = 는 같다가 아니라 담아라
수학에서 `a = a + 1`은 말이 안 되는 식이다. 하지만 프로그래밍에서는 말이 된다.

```python
a = 10
a = a + 1
print(a)  # 11
```

`=`는 **오른쪽을 먼저 계산해서 왼쪽에 담는** 대입 연산자이기 때문이다. 그래서 "같다"는 `==`로 따로 쓴다.

값을 코드에 그때그때 직접 써넣으면, 같은 값을 바꿀 일이 생겼을 때 전부 찾아서 고쳐야 한다. 이름을 붙여두면 한 곳만 고치면 되는데, 그게 변수라고 이해했다.

## 변수는 타입까지 바뀐다
```python
a = 10          # int
a = 20          # 값 변경
a = 3.14        # 타입까지 바뀜 (int → float)
print(type(a))  # <class 'float'>
```

파이썬은 같은 변수에 다른 타입의 값을 다시 담을 수 있다. 편하지만 그만큼 위험한 부분이기도 하다.

오늘 강사님이 강조하신 문장이 있다.

> 프로그래머는 변수에 어떤 타입의 어떤 값이 담겨 있는지 놓치면 안 된다.

그리고 없는 변수는 사용할 수 없고(`NameError`), 대소문자도 구분한다. `a`와 `A`는 다른 변수다.

## 형변환
어제 `"55" + 31`이 에러가 나는 것을 봤는데, 이걸 해결하는 방법이 형변환이다.

```python
age = 10
# print('제 나이는' + age + '살')        # TypeError
print('제 나이는 ' + str(age) + ' 살 입니다.')  # str() 로 글자로 바꾼다

num = "100"
print(int(num) + 2)  # 102  int() 로 숫자로 바꾼다
```

형변환 함수는 타입 이름과 똑같다. `int()`, `float()`, `str()`, `bool()`이다.

```python
print(float(10))   # 10.0
print(int(3.14))   # 3      반올림이 아니라 버림
print(bool(0))     # False  0만 거짓
print(bool(1))     # True   0 이외는 전부 참
print(int(True))   # 1
```

`int(3.99)`가 4가 아니라 3이 나온다는 점, 그리고 `int("3.14")`는 에러가 나서 `int(float("3.14"))`처럼 두 번 거쳐야 한다는 점은 따로 기억해둬야 할 것 같다.

## 콤마 vs + 로 출력하기
```python
my_name = "최홍묵"
print('제 이름은', my_name, '입니다.')      # 콤마: 자동으로 띄어쓰기, 형변환 불필요
print('제 이름은 ' + my_name + ' 입니다.')  # +: 띄어쓰기 직접, 타입도 맞춰야 함
```

콤마로 넘기면 알아서 띄어쓰기를 넣어주고 형변환도 필요 없다. `+`는 하나의 문자열 덩어리를 만들어야 할 때 쓴다.

## 변수 이름 규칙과 여러 값 대입
변수 이름에는 알파벳, 숫자, `_`를 쓸 수 있다. 숫자로 시작할 수 없고, 띄어쓰기와 특수문자도 안 된다. `if`, `for`, `class` 같은 **예약어**도 쓸 수 없다.

```python
a, b, c = 100, 200, 300   # 한 줄에 여러 변수

a, b = 11, 33
temp = a; a = b; b = temp  # 전통적인 swap: 임시 변수가 필요하다
a, b = b, a                # 파이썬식 swap: 한 줄
```

`a, b = b, a` 한 줄로 두 값을 맞바꿀 수 있는 것이 신기했다. 면접에서도 자주 나온다고 한다.

복합 대입 연산자도 배웠다.

```python
a += 1   # a = a + 1
a *= 2
a -= 1
a %= 2
```

## print()의 end와 sep
`print()`가 출력 후 자동으로 줄을 바꾸는 이유는 `end`의 기본값이 줄바꿈이기 때문이다.

```python
print(10, end="*")      # 줄바꿈 대신 * 를 붙인다
print("Hello", end='')  # 아무것도 안 붙인다
print(3.14)
# 결과: 10*Hello3.14

print(10, 20, 30, sep="**")  # 10**20**30
```

`sep`은 여러 값을 콤마로 넘겼을 때 **값 사이에** 넣을 문자열이다. 기본값은 공백 한 칸이다.

## 이스케이프 문자와 r-string
키보드로 직접 칠 수 없는 문자는 `\` 조합으로 표현한다.

```
\n  줄바꿈
\t  탭
\\  역슬래시 자체
\'  \"  따옴표 자체
```

```python
print("He \nsays \"I'm fine\"")
```

문제는 윈도우 경로다. 경로 구분자인 `\`가 이스케이프 시작 기호와 겹친다.

```python
path = "C:\Program Files\Microsoft\011_python\times"
print(path)  # \t 가 탭으로, \011 이 이상한 문자로 바뀐다

path = "C:\\Program Files\\Microsoft\\011_python\\times"  # 방법 1: \\ 두 번
path = r"C:\Program Files\Microsoft\011_python\times"     # 방법 2: r-string
```

`r`은 raw의 약자로, 이스케이프 처리하지 말고 글자 그대로 보라는 뜻이다. 나중에 정규표현식을 배울 때 거의 필수로 쓰인다고 한다.

## 포맷팅 3가지 방법
값을 문장 안에 끼워 넣는 방법은 세 가지가 있다.

### % 연산자 (옛날 방식)
```python
a = "My name is %s, I'm %d yrs old" % ("최홍묵", 31)
print("원주율은 %.2f 입니다" % 3.141592)
print("%5d:%5d" % (10, 100))    # 5칸 오른쪽 정렬
print("%-5d:%-5d" % (10, 100))  # 5칸 왼쪽 정렬
```

`%d`는 정수, `%f`는 실수, `%s`는 문자열이다.

### .format()
```python
"My name is {}, I'm {} yrs old".format("최홍묵", 31)
"My name is {name}, I'm {age} yrs old".format(age=31, name="최홍묵")
"원주율은 {p:.2f} 입니다.".format(p=3.141592)
```

### f-string
```python
lang = 'Python'
pi = 3.141592

print(f"Language: {lang}")
print(f"원주율은 {pi:.2f} 입니다.")    # 원주율은 3.14 입니다.
print(f'num은 {1234567890:,} 입니다.')  # 1,234,567,890
```

f-string은 **중괄호 안에 변수 이름을 그대로 쓴다**는 점이 핵심이다. 앞의 두 방법은 값을 따로 넘겨서 몇 번째 자리에 무엇이 들어가는지 세어야 했는데, f-string은 그럴 필요가 없다.

직접 쓸 때는 f-string만 쓰면 되지만, 다른 사람의 코드나 오래된 문서에는 `%`와 `.format()`도 나오니 읽을 줄은 알아야 한다.

## 정렬 서식으로 표 만들기
세 방법 모두 같은 결과를 낼 수 있다.

```python
area, pop, inc = "Seoul", "10,312,545", "+91,375"

print("%15s%15s%15s" % (area, pop, inc))           # % 방식
print("{:>15}{:>15}{:>15}".format(area, pop, inc))  # format 방식
print(f"{area:>15}{pop:>15}{inc:>15}")             # f-string
```

`:>15`는 15칸을 확보하고 오른쪽 정렬, `:<15`는 왼쪽 정렬, `:^15`는 가운데 정렬이다.

## 헷갈리기 쉬운 부분
- f-string에서 `f`를 빼먹으면 `{pi:.2f}`라는 글자가 그대로 찍힌다.
- 경로 문자열 안에 `\t`, `\n`이 숨어 있으면 문자열이 망가진다. 경로에는 `r"..."`를 쓰자.
- `print(b = 20)`은 에러다. 꼭 필요하면 워크러스 연산자 `:=`(`print(b := 20)`)가 있지만, 읽기 어려워져서 수업에서는 가급적 쓰지 말라고 하셨다.

## 오늘 배운 내용 정리
오늘은 변수와 형변환, 그리고 출력 포맷팅을 배웠다.

```
= : 오른쪽을 계산해서 왼쪽에 담는다. 같은지 비교는 ==.
변수: 값에 붙이는 이름표. 담긴 값과 타입이 바뀔 수 있다.
형변환: int(), float(), str(), bool(). int() 는 반올림이 아니라 버림.
swap: a, b = b, a 한 줄로 값을 맞바꾼다.
print(): end 는 출력 뒤에 붙일 것, sep 은 값 사이에 넣을 것.
이스케이프: \n 줄바꿈, \t 탭. 경로에는 r"..." 를 쓴다.
f-string: f"{변수:서식}" → :.2f 소수 자리, :, 천 단위 콤마, :>15 자리 맞춤.
```

오늘은 특히 f-string이 편하다는 걸 많이 느꼈다. `+`와 `str()`이 뒤엉킨 코드보다 훨씬 읽기 쉽다.

`:.2f`, `:,`, `:>15` 같은 서식은 정올 문제를 손으로 여러 번 풀면서 익숙해져야 할 것 같다.
